## Comment booker

1. Compte e-mail **avant**. NIF facture : **Não**. Passeport **pas** exigé par l’IFCN pour un visiteur (le garder quand même).
2. Service Percursos → **Ver disponibilidade** → code PR (**PR1 complet**, pas Pedra Rija).
3. Date + créneau 30 min → confirmer.
4. Effectifs : **2** non-résidents > 12 ans.
5. « Ajouter une autre réservation ? » → **Sim** pour enchaîner (pass auto).
6. **Pagar** — Visa/Mastercard. MB WAY = comptes PT.
7. E-mail : billets + QR + facture. Captures **plein écran** + PDF hors-ligne + 1 jeu imprimé.

Langue souvent PT. Contacts : SIMplifica **800 299 090** / WhatsApp **+351 926 155 465** · IFCN **+351 291 145 590**.
