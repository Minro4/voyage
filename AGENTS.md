# Voyage

This project helps organize a **trip to Madeira** (6–19 September 2026; fly out **Saturday 19 morning**).

## Trail notes

### Reservations (SIMplifica) — required since Jan 2026

**Yes — all IFCN classified PR trails need a prior online reservation** via [SIMplifica](https://simplifica.madeira.gov.pt). No walk-up / pay-at-trailhead for IFCN trails. Bookings are **not** done at IFCN offices.

| Rule | Detail |
| --- | --- |
| Who must book | Everyone (residents exempt from fee but still must register) |
| Slot | 30-minute entry window — start within that slot |
| Same-day / next-day | Allowed **if slots remain** (official FAQ) |
| In advance? | Strongly recommended for popular trails — they sell out |
| Book early for | **PR1** (Areeiro–Ruivo), **PR6** (25 Fontes), **PR9** (Caldeirão Verde), **PR8** (São Lourenço) |
| Fees (non-residents) | Most trails **€4.50**; full **PR1 €10.50**; under-12 free (still book); multi-trail day/3/7-day rates auto-applied |
| Proof | Keep QR / confirmation on phone; checked at trailheads |

**Practical takeaway for this trip:** you *can* book once on the island if anything is left, but for PR1 / 25 Fontes / Caldeirão Verde / São Lourenço, **book before arrival** (or as soon as dates are firm). A 7-day combined pass (€52.50) can be economical for many hikes — still need a separate slot reservation for each trail.

### PR1 – Vereda do Areeiro (Pico do Areeiro → Pico Ruivo)

Closed for boardwalk works during the trip:

- **14, 15, 16, 17 September** (within trip dates)
- Also 21–22 September (after departure)

Outside those dates: open daily, **one-way only** (Areeiro → Ruivo), mandatory **SIMplifica** booking. Do not plan PR1 for 14–17 Sep.

### 14–15 — côte (plan A) · cottage Rabaçal = repli

**Plan A:** sleep in town (Prazeres / Calheta / Jardim). After PR6, take the municipal shuttle **up** to ER 105 **before 18:00**, then a **pre-booked taxi** to the hotel. Tuesday morning: taxi **07:00–07:30** back to the **ER 105 car park** (not the cottage door). Walk down 20–40 min to start toward Chão.

**Backup:** Rabaçal Nature Spot Cottage (half board, Tuesday starts at the door — no evening/morning taxis).

**No city bus from the valley.** The cottage is 30–40 min walk below the ER 105 plateau road.

The only scheduled vehicle is Calheta’s **municipal shuttle** (not an on-demand taxi):

- Loops the 2 km paved road: cottage / Casa Florestal ↔ ER 105 car park (Miradouro do Rabaçal)
- Daily **10:00–18:00**
- **€5** one way / **€8** return (cash)
- Wait at the forestry house / shuttle stop (ask on site where to stand)
- Driver (to ask when the next loop is, not door pickup): **+351 966 426 851**
- Official: [Transporte no Rabaçal](https://cmcalheta.pt/pt/visitar/percursos-pedestres/transporte-no-rabacal)
- English (PR6 page): [PR 6 – Levada das 25 Fontes](https://www.cmcalheta.pt/en/visit/walking-routes/list-of-routes/pr-6-levada-das-25-fontes)
- Cottage listing: [Booking.com](https://www.booking.com/hotel/pt/rabacal-nature-spot-cottage.html)

SIGA **380/381** (Funchal–Porto Moniz via Calheta) is a **coastal** route (Calheta, Prazeres, etc.). It does not serve the cottage.

**To sleep in a town (this trip’s plan A):** shuttle (or walk) to ER 105 **before 18:00**, then a **pre-booked taxi**. Options: **Prazeres / Calheta / Jardim** (~15–35 min). Plateau is empty after the last shuttle. Fallback: 30–40 min steep walk up — do not leave this late.

Cottage café 10:00–18:00. Four rooms on site **if using the backup** instead of exiting.
