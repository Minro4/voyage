# Potential destinations

Week-scale mountain treks under consideration (separate from the Madeira trip, 6–19 September). Focus: ~7 days on trail, September-friendly where noted.

---

## GR20 (Corsica) — half trek

Europe’s classic hard granite ridge trek. Full route is Calenzana → Conca (~180 km, ~10–16 days). A **half trek** is the usual 7–8 day option.

| | Detail |
| --- | --- |
| Location | Corsica, France |
| Duration (half) | ~7–8 days |
| Options | **North** Calenzana → Vizzavona (harder, more scrambling/exposed); **South** Vizzavona → Conca (still tough, slightly less technical) |
| Difficulty | Very hard — steep daily elevation, rocky/exposed sections, weather-dependent |
| Best for September? | **Yes** — one of the better windows: cooler than Jul/Aug, fewer crowds, mostly snow-free |
| Season caveats | Finish by ~25 Sep for full refuge services; late month thins out. Nights cold on ridges; water scarcer later in Sept |
| Logistics | Refuge/camping booking needed in season; early starts; mountain weather flips fast |

**Verdict:** Strong September pick if you want a committing, technical week. North half ≈ GR20’s signature feel; south half is a slightly kinder first exposure.

## Picos de Europa (northern Spain)

Limestone massifs spanning Asturias, Cantabria, and Castilla y León. More “karst mountain circuit” than Corsica’s continuous granite ridge — deep gorges, fog, steep canals, and hut-to-hut stages.

### Best multi-day match: El Anillo de Picos (Ring of the Peaks)

Hut-to-hut network with three length options:

| Variant | Rough scale | Notes |
| --- | --- | --- |
| **Anillo Vindio** | ~4 days / ~63 km | Western (Cornión) massif only — shorter entry to the hut circuit |
| **Anillo Extrem** | ~6 days / ~82 km | Western + central (Urrieles); includes hard high ground, skips eastern Ándara |
| **Anillo Tres Macizos** | **7–9 days** / ~110–115 km / ~9,000 m ascent | Full ring across all three massifs — the ~week trek |

| | Detail |
| --- | --- |
| Typical start | Poncebos (road/bus access via Arenas de Cabrales); also Posada de Valdeón, Sotres, etc. |
| Difficulty | Hard — for experienced mountain hikers. Long days, steep descents, loose limestone, exposure; **not consistently waymarked**; fog (`encainada`) makes navigation serious |
| Terrain vs GR20 | Less continuous scrambling/chain sections than GR20 north; still very physical. Water scarcity between huts (limestone swallows springs) |
| Best for September? | **Yes** — season is roughly June–September. Sept quieter than Jul/Aug; valleys still warm; high passes can be cold; first autumn snow possible late month |
| Refuges | Book ahead (essential in summer weekends). Key stops include Vega de Ario, Vegarredonda, Vegabaño, Collado Jermoso, Cabaña Verónica, Casetón de Ándara, Vega de Urriellu, Jou de los Cabrones |
| Highlights | Cares corridor, Picu Urriellu (Naranjo de Bulnes) base, Collado Jermoso views, Áliva pastures |
| Access | Fly Asturias / Santander / Bilbao → bus/taxi/car into Arenas de Cabrales, Cangas de Onís, Potes, or Valdeón |

**Practical notes**
- No special trek permit usually required; **hut reservations are the bottleneck**.
- Carry full-stage water every day; fill at refuges.
- Take offline GPX + map — do not rely on phone signal or continuous blazes.
- Wild camping is restricted; check with wardens / park rules.
- Alternative if you want variety without a continuous loop: **GR-202 Ruta de la Reconquista** (Covadonga → Cosgaya, often guided as ~5 days) hits lakes, Cares, Bulnes/Sotres, Áliva — more point-to-point / mixed lodging than pure Anillo.

### Day-hike / soft week fallback

If not doing the Anillo: base in Arenas / Cangas / Potes for a road-supported week — **Ruta del Cares** (Poncebos–Caín, ~11–12 km one way, moderate, iconic gorge), Bulnes / Urriellu approaches, Covadonga lakes, Fuente Dé / Horcados Rojos. Excellent September; Cares is busy in peak summer.

**Verdict:** Tres Macizos is the closest Picos answer to a “GR20 half” week — serious hut-to-hut, September-friendly, logistics via northern Spain rather than Corsica. Vindio/Extrem if you want fewer days or a first Picos circuit. Easier than GR20 north overall, but do not treat it as casual walking.

## Rough comparison (week trek)

| | GR20 half | Picos Anillo (Tres Macizos) |
| --- | --- | --- |
| Days | ~7–8 | ~7–9 |
| Feel | Hard granite ridge, scrambling | Limestone massifs, gorges, fog |
| Technical | North half high; south moderate-high | High fitness + navigation; less via ferrata-style scrambling than GR20 |
| Crowds in Sept | Lower after mid-month | Quieter than Jul/Aug |
| Booking | Refuges / campsites | Refuges essential |
| Getting there | Fly into Corsica (or ferry) | Asturias / Santander / Bilbao + transfer |
